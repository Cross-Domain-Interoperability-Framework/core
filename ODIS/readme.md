# import core odis patterns specifications


This Directory hosts CDIF Core templates serialised in JSON-LD using schema.org as a semantic context. Extended semantics can be added using additionalProperty properties or PropertyValue types. These are from https://github.com/Cross-Domain-Interoperability-Framework/core/tree/1-import-core-odis-patterns-specifications/json-ld/schema, and see https://github.com/Cross-Domain-Interoperability-Framework/core/pull/2.  Many of the types are not used by the CDIF profiles at this point. A similar modularization approach has been implemented with the OGC building blocks.
